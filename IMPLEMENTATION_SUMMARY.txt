🚀 USAGE (5 MINUTES TO CREATE A SECTION)
-----------------------------------------
1. Define type (extends BaseItem)
2. Create card component
3. Use useSectionManager hook
4. Render with SectionContainer + ItemList

Example:
```typescript
const { items, add, update, remove, saveStatus } = 
  useSectionManager<YourItem>({
    initialData: data.items || [],
    onSave: async (items) => { /* save */ },
    autoSave: true,
  });

return (
  <SectionContainer
    title="Your Section"
    icon="🎯"
    onAdd={handleAdd}
    status={saveStatus}
  >
    <ItemList
      items={items}
      onReorder={reorderByIndex}
      renderItem={(item) => (
        <YourCard
          item={item}
          onUpdate={update}
          onDelete={remove}
        />
      )}
    />
  </SectionContainer>
);
```
